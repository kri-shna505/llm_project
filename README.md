# LLM Project

Small experiments building LLM applications in Python.

## Project Structure

- main.py — entry point
- .gitignore — ignored files configuration

## Setup

```bash
python -m venv venv
venv\Scripts\activate
pip install -U pip
```

## Run

```bash
python main.py
```

## Goal

Learning how to build and version-control LLM applications properly.
